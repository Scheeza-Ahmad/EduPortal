PHASE 1 — AUTHENTICATION & SUPER ADMIN
Duration: Weeks 2–4
Status: CURRENT
----------------------------------------------------------------

Security Measures (applied in this phase, used throughout):
  - JWT access token (15min) stored in JS memory only
  - JWT refresh token (7d) in httpOnly + Secure + SameSite cookie
  - Bcrypt password hashing (rounds = 12)
  - express-rate-limit: max 5 login attempts per IP per 15 min
  - Helmet.js: secure HTTP headers (XSS, clickjacking, MIME)
  - Zod: input validation on every endpoint
  - CORS: only allow frontend URL
  - Soft delete: never hard delete any record
  - Audit log: every sensitive action recorded automatically
  - Never return password hash in any API response

Module: Auth System
  - JWT login / logout
  - Refresh token rotation
  - Password reset via email (OTP, 10-minute expiry)
  - RBAC middleware (role-based route protection)
  - Super Admin account seeded via script (not self-registerable)

Module: Super Admin Dashboard
  Features:
    - Create / edit / disable / soft-delete schools
    - Assign School Admin to a school
    - Platform-wide stats dashboard
        (total schools, total users by role, submissions, storage)
    - Enable / disable features per school (feature flags)
        (parent portal, AI features, SMS, Urdu toggle)
    - Full audit log viewer
        (filterable by school / user / action / date, CSV export)
    - Manual database backup trigger (Supabase export → Cloudinary)
    - User impersonation (with automatic audit log entry)
    - Suspicious login alert (3 failed attempts → email to super admin)

  Automations (cron jobs):
    - weeklyBackup.ts     → Every Sunday 00:00 — DB backup
    - monthlyReport.ts    → 1st of month 08:00 — health report PDF emailed
    - storageWarning.ts   → Daily check — alert if storage > 80%
    - suspiciousLogin.ts  → Real-time — 3 failed logins trigger email

  NOTE: School inactivity alert deliberately excluded.

Deliverables:
  - /api/auth/* endpoints complete and tested
  - Super Admin panel fully functional (frontend + backend)
  - RBAC middleware protecting all routes
  - All 4 Super Admin automations running
  - Security middleware stack applied (Helmet, rate-limit, Zod, CORS)
